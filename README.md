# Team Task Management

This repository is organized into one work area per Git branch. Each branch contains
the shared project overview and its matching folder:

| Branch | Folder | Purpose |
| --- | --- | --- |
| `frontend` | `frontend/` | User interface work |
| `backend` | `backend/` | Application and API work |
| `database` | `database/` | Data model and persistence work |
| `testing` | `testing/` | Test plans and quality checks |
| `documentation` | `documentation/` | User and developer documentation |

Start from the branch matching the area you are working on. Keep that branch's
changes in its matching folder.
